# 2026-10-02 LP 実写写真ベース刷新

## 対象
- 公開LP: `lp.html`
- PC / スマホ両対応

## オーナーが決定した方向
- イラスト調の車内画像は使わず、**実写・フォトリアルな電車内画像を主役にする**
- 首都圏の一般的な通勤電車を前提にする
- 座席は**ロングシート**。乗客は進行方向ではなく、車体側面に対して向かい合う座り方にする
- 車内案内表示は**扉の上**にある構図にする
- 「席に座ると扉上の表示が人に隠れて見えない」という利用課題をヒーローで伝える
- LPは、決定したモックアップのように
  - 大きな実写ヒーロー
  - 実写の利用シーン
  - スマートフォンのエキココUI
  - 白基調の本文エリア
  を組み合わせる
- 四角いカードを大量に並べるSaaS風の見た目にはしない

## 参考画像
- `reference.png`
- これは決定した方向を実装担当へ渡すための参考ビジュアル
- **画像をそのままLP全面に貼るのではなく、HTML/CSSで構成を再現する**

## ヒーロー
### コピー
```
席に座っても、
今どの駅かすぐわかる。
```

### 説明
```
エキココは、電車の中で現在駅をすばやく確認するためのシンプルなWebアプリです。
乗換案内ではなく、移動中の「今ここ」に特化しています。
```

### CTA
- 主: エキココを開く
- 副: できることを見る

### 補助情報
- アカウント登録不要
- ブラウザですぐ使える
- PWA対応

## ページ構成
1. 白いヘッダー
2. 実写ヒーロー
3. 「こんな場面で役立ちます」
   - 席に座ると扉上の表示が見えない
   - アナウンスを聞き逃す
   - 今の駅だけすぐ確認したい
4. 「エキココでできること」
   - 現在駅を大きく表示
   - 車内モード
   - 目的地設定
   - 駅情報 / 乗り方ガイド
5. 車内モードの紹介
6. 3ステップ
7. CTA

## 実装上の注意
- PCとスマホは単純縮小ではなく、ヒーローのクロップ・情報密度を個別調整する
- スマホでは1カラムを基本にする
- 写真上の文字は必ず十分なコントラストを確保する
- スクロール演出は短いfade / translate程度。派手なパララックスは不要
- `prefers-reduced-motion` 対応
- アプリ本体の機能・ID・JS契約は変更しない
- 静的アセット変更後は `python3 tools/bump_cache.py` を実行する
