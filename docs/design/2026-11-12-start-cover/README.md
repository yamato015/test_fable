# アプリ開始画面：写真を使った新しい構成

2026-11-12、オーナーの「ガラッとデザインから変えて」を受けた実装。直前の画面は https://8917be3b.ekikoko.pages.dev/ で比較できる。

## 対象・方針

アプリの開始画面。上下に小さなカードを並べた構成から、大きな駅の写真と、操作をまとめた下部パネルへ組み直した。濃紺・白・ライム色を使い、ブランド名と言語選択を写真の上部、見出しを写真の中央に重ねる。現在地を確認するボタンを最も目立つ操作にし、その下に位置情報なしで読める乗り方ガイドを置く。

画像にUIや文字を焼き込まず、見出し・ボタン・説明はHTMLテキストで実装。生成した背景写真は架空の駅のイメージであり、現在地やライブ映像を示すものではない。画像は装飾として読み上げ対象から外した。素材は `assets/lp/start-night-rail-v1.jpg`（800×1200、約194KB）。組み込みの画像生成機能で作成し、Web用にJPEGとして最適化した。

動きは写真の寄り引き、短い光のライン、ボタンの反射と登場演出。停止・再開と端末内への選択保存、OSの動きを減らす設定を尊重する。開始画面が隠れたとき・ガイド表示中は繰り返す動きを停止する。

## 確認

- Chromeで320px英語、390px日本語、1512pxのダーク表示を確認。横はみ出しなし。
- 固定座標のサンプルで、新しい開始ボタンから新宿のメイン画面に進めること、ガイドを開けることを確認。実際のGPS権限は使用していない。
- 動きの停止と、開始画面が隠れた際の停止を確認。
- JavaScript構文・公開ビルド・空白差分チェック成功。実機iPhoneでの操作や電池消費は未計測。
