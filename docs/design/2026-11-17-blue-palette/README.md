# アプリの青・白・濃紺の配色

2026-11-17、オーナーの「実際のアプリも黄色消して欲しい」を反映。

- 開始画面の写真・アニメーションと駅名画面の構成は維持し、装飾・ボタン・背景・ガイド・車内モードを青系へ変更。
- 基本色はブルー `#1464ff`、白 `#f7faff`、濃紺 `#07142c`。暗い面上の文字やアイコンにはシアン `#7ed9ff`。ライトモードの小さい文字は濃い青で可読性を確保。
- ゴールドの配色選択を廃止。保存済みの旧設定・初回起動はブルーへ。ピンクを選んだ人の設定は維持する。
- ホーム画面用アイコンも既存の形を保って青系へ。実路線の識別色は変更しない。
- 位置取得・目的地保存など機能の変更はない。写真内の照明や路線の黄色は意味のある実景・案内色として残る。

## 確認

Chromeで公開前の開始画面と、固定座標サンプルの駅名・車内モード・設定・ガイドを確認。日本語ライト390px、英語ダーク320pxで横はみ出しなし、コンソールエラーなし。既存の位置更新テスト18件と、旧設定・新規・ピンクなど5ケースの配色移行チェックが成功。キャッシュはv73。実機での移動確認は別途。
