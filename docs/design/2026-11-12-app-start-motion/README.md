# アプリ開始画面のアニメーション

2026-11-12、オーナーの「アプリの最初の画面もアニメーションつけて」という依頼を実装。

## 変更

- 既存の写真と文言を使い、タイトル・写真・操作ボタンが順に現れる。
- 写真を14秒周期で緩やかに動かし、10秒周期で車窓の反射のような光を重ねる。新しい画像・動画のダウンロードは不要。
- 「動きを止める／再開」を日英で表示し、端末内に選択を保存する。
- OSの「動きを減らす」を尊重する。開始画面が隠れたとき、写真が画面外に出たとき、別タブに移ったとき、ガイド等のシートを開いたときは写真の動きを止める。
- アニメーションの終了を待たずにボタンを操作できる。乗り方ガイドの既存アニメーションには変更を加えない。

## 実装と確認

`app-start-motion.css` と `app-start-motion.js` に開始画面の表現を限定。公開ビルドとオフラインキャッシュに両ファイルを追加し、キャッシュ版を v66 に更新。

Chromeの320px・390px・1512px幅で横はみ出しなしを確認。写真の実際の変化、停止中に動かないこと、再読み込み後の停止状態保存、日英切替、ガイド表示中の停止と閉じた後の再開を確認。JavaScript構文チェックと公開ビルドが成功。OSの動きを減らす設定への対応はコードで確認。実機iPhoneでの操作・電池消費は未計測。

オーナーの「もっと派手にしてみて」という依頼で、背景の色が移動する光・回転する軌道と流れるラインを追加。タイトルは横から、写真は奥行きと傾きを伴って現れるように変更し、写真の拡大・横移動・傾きも強めた。ボタンの反射とタイトル下の伸縮するラインも追加。

繰り返す演出はすべて既存の停止・再開と画面の表示状態に連動する。OSの動きを減らす設定では背景演出と連続する動きを無効にする。装飾は読み上げ・クリックの対象外。画像・動画や依存ライブラリの追加はない。キャッシュ版はv67。
