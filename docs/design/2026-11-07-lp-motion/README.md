# 採用したLPの動き

対象は `lp.html`。オーナーが2026年11月7日に、強め版の実装プレビューを「これでいいと思う」と選択した。

- 確認したプレビュー: https://ba6da0f5.ekikoko.pages.dev/lp
- 実写と実画面は既存素材を維持し、見出し・写真の登場、画面の浮遊、光と線の背景、マウスへの小さな傾きをCSSとJavaScriptで実装する。
- 公開版は比較ツールを表示せず、継続する動きを利用者が止められるボタンを残す。
- `prefers-reduced-motion` と、画面外・非表示タブの停止を維持する。
- 新しい動画・GIFファイル、有料サービス、棒人間の説明素材は追加していない。
- 実際の端末での電池消費とFPSは未測定。動きの強さは今後の感想で調整できる。

実装ファイルは `lp-motion.css` と `lp-motion.js`。元の静止版と穏やか版はGit履歴と既存プレビューに残る。
