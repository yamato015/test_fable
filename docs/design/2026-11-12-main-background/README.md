# アプリ本体の背景デザイン

2026-11-12、オーナーの「開いた後の背景もデザインつけて欲しい」に対応。対象は開始後の現在駅・周辺駅を表示するメイン画面。

## 変更

- 上部に既存の夜の駅の写真を使い、濃紺の重ね色と白いブランド表示を配置。
- 駅名カードが写真の上に重なる構成と陰影で奥行きをつくる。
- 下部には淡いライム色・青緑の光と、路線を連想させる細い曲線を敷く。曲線は装飾で、実際の路線図を示さない。
- ライト／ダーク設定に合わせて背景色を変更。表示設定と既存の配色選択を維持。
- 追加の背景は静止画とCSS。画像は開始画面の素材を再利用し、新しい画像や常時アニメーションは追加していない。

`app-main-background.css` に対象を限定し、公開ビルドとキャッシュに追加。キャッシュはv70。路線選択チップ・路線フィルターが表示される場合の上部余白も調整。

## 検証

固定座標の新宿サンプルで、390px幅の日本語ライト表示と320px幅の英語ダーク表示、路線選択後のチップ・駅名カードを確認。320pxの横はみ出しを修正し、画面幅とページ幅が一致することを確認。設定ダイアログ、背景を含む表示切替、コンソールエラーなしを確認。公開ビルドと空白差分チェック成功。実機iPhoneの位置取得や電池消費は今回計測していない。

## 位置情報なしの確認先

`codex/app-main-background-20261112` の確認用ビルドに限り、`app-preview.html` と `app-preview-runtime.js` を生成する。元の確認用ブランチも維持。本番ブランチでは生成しない。サンプルは実GPS・通知・解析・Service Workerを無効にし、新宿の固定座標と専用の保存キーを使用する。
