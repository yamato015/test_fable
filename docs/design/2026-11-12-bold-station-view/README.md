# 駅名画面のデザインを強める

2026-11-12、オーナーの「もっとがっつりデザイン性持たせていいよ」を受け、アプリ開始後の駅名画面をまとめて再設計した。以前の版は https://dd0b75fc.ekikoko.pages.dev/app-preview で比較できる。

## 変更

- 駅名を大きな白文字で見せる濃紺のパネルと、控えめな円弧の装飾。路線色・GPS状態・手動更新・乗り換えの情報をパネル内に整理。
- 車内モードは明るい操作カード、降りる駅の選択は白系のカードとして、操作の強弱を明確にする。ブルー／ピンクの配色設定にも連動。
- 角丸、余白、アイコン、文字サイズ、カードの陰影を揃える。
- 周辺駅は距離順の連番と路線色のレールを添えた一覧へ。長い駅名は複数行で読める。
- 下部のナビゲーションを、濃紺の浮かぶパネルに変更。
- ライト／ダーク表示に対応。背景・駅名パネルの装飾は静的なCSSで、画像や常時アニメーションの追加はない。

主な変更は `app-main-background.css` に限定。主画面の長い駅名の文字サイズを切り替える基準だけ `app.js` で調整した（日本語4文字以上・英語13文字以上）。駅の判定・位置取得には変更を加えていない。キャッシュはv71。

## 確認

Chromeで390px幅の日本語ライト、320px幅の英語ダークとブルー配色、周辺駅のリスト、設定ダイアログと配色切替を確認。横はみ出しなし、コンソールエラーなし。既存の位置更新・乗車路線のテスト18項目が成功。JavaScript構文チェック・公開ビルド・空白差分チェックも成功。実機iPhoneでの操作や電池消費は未計測。

## 確認用の見本

`codex/app-bold-design-20261112` の確認用ビルドに限り、固定座標のサンプルが駅名画面を直接開く。実GPS・通知・解析・Service Workerは無効。既存の確認用ブランチは維持し、本番ビルドにサンプルは含めない。
