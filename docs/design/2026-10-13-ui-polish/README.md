# 画面の優先順位と図解の仕上げ — 2026-10-13

## 指示
「その改善点を意識しながら修正・改善して」。全要素の主張の強さ、細かな英語ラベル、単純なガイド図を見直す。棒人間を使わず、ガイドは動く図解を継続する。

## 反映
- 駅名カードと車内モードを主役にし、目的地・ガイド・周辺駅の装飾を抑える。主要カードに濃淡と控えめな接地影を残す。
- 重複する英語ラベル・装飾番号を除去し、設定の言語・表示・テーマ名を読みやすくする。
- 改札・カード・きっぷ・窓口・精算機・乗換の6図を描き直す。人物は描かず、面の濃淡と実際の読み取り位置を使って手順を説明する。
- 1回再生と再生ボタン、動きを減らす設定への既存対応を継続する。
- 検索の選択タブを明確にし、駅名と路線情報を上下に分ける。位置情報エラー時の空白と重複表示を減らす。
- LPの見出し・余白・写真グリッドを整え、アプリ紹介用SVGを現在のUIに合わせる。

## 検証
- Chromeの320px / 390px幅、日本語 / 英語、ライト / ダークで主要画面・ガイド・検索・設定・位置情報拒否画面を確認。
- 車内モードの黒背景・大きい駅名・戻る操作を確認。ローカルの駅表示は新宿の固定テスト座標を使用し、テスト用HTMLは公開対象に含めない。

- ブラウザのエラーログは空。車両内でのGPS精度や実機の乗車試験は今回の検証に含まない。
