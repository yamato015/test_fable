# AIの役割分担と受け渡しルール

エキココ（および ttx の事業全般）では、複数のAIを役割ごとに使い分ける。
このリポジトリに関わるAI（Claude / Claude Code / ChatGPT / Codex など）は、
作業前にこの文書を読み、自分の担当外のことは担当側へ渡すこと。

**最終的な決定は常にオーナー（ttx）が行う。** AIは提案・実行・検証を担う。

## 役割分担

| 領域 | 担当 | 内容 |
|---|---|---|
| 事業としての議論 | **Claude** | 戦略、収益化、優先順位、数字の試算、リスク整理など |
| LP・HPのデザイン | **ChatGPT** | ページの構成・見た目のデザイン案 |
| デザイン用の画像生成 | **ChatGPT** | LP・HP用のイメージ画像、ビジュアル素材 |
| 議論の客観視点 | **ChatGPT** | Claudeとの議論で出た結論を、第三者の立場でレビュー・反論する |
| コードの実装 | Claude Code / Codex | このリポジトリを直接編集して、決まった内容を反映する |

> 実装の担当は、オーナーが明示的に決めたものではなく、これまでの運用
> （Claude Code と Codex の両方がこのリポジトリを編集している）を記載したもの。

## 受け渡しのルール

### 1. デザイン（ChatGPT → 実装担当）

1. ChatGPTで作ったデザイン案・画像のうち、**オーナーが「決定」としたもの**を
   `docs/design/YYYY-MM-DD-<内容>/` に保存する（画像ファイル＋`README.md`）
2. `README.md` には次を書く
   - どの画面・どのページのデザインか
   - 決定した点 / 参考程度の点（そのまま再現すべきか、雰囲気だけ採るか）
   - ChatGPTが出した色・文字サイズなどの指定があれば、その原文
3. 実装担当は、画像を**そのまま貼り付けず、HTML/CSSで作り直して反映**する
   - 画像内の日本語は崩れていることが多いので、文言はテキストで書き直す
   - 実装できない表現は、雰囲気を保った実装可能な形に置き換え、
     置き換えた箇所を `README.md` に追記する
4. 反映後、デザイン画像と実装のスクリーンショットを並べて確認する

### 2. 議論の客観レビュー（Claude → ChatGPT → オーナー）

1. Claudeとの議論で結論が出たら、Claudeにその結論を下の形式でまとめてもらう
2. オーナーがそれをChatGPTに貼り付け、下のテンプレートでレビューを依頼する
3. ChatGPTの指摘を受けて、オーナーが最終判断する
4. 決まった内容は `docs/decision-log.md` に記録する

**ChatGPTに貼るレビュー依頼テンプレート**

```
以下は、別のAI(Claude)と議論して出した事業上の結論です。
あなたは利害関係のない第三者として、この結論をレビューしてください。

- 前提や数字に誤り・根拠の弱いところはないか
- 見落としているリスクや、別の選択肢はないか
- 結論に反対するとしたら、最も強い反論は何か

忖度せず、事実と推測を分けて指摘してください。

---
[ここにClaudeがまとめた結論を貼る]
```

**Claudeが結論をまとめるときの形式**

```
## 議題
## 結論
## 根拠(事実 / 推測を区別)
## 前提にしている数字
## 検討して捨てた選択肢と理由
## 未解決の論点
```
