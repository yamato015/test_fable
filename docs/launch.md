```
# 電車で「今どの駅？」をなくすアプリ「エキココ」をβ公開しました

混雑した電車で座っていると、車内の電光掲示板が人で隠れて見えず、
今どの駅にいるのか分からない——この地味なストレスを解決したくて作りました。

## できること
- GPSで最寄り駅を画面いっぱいに特大表示。座ったままチラ見で確認
- 車内モード：画面が消えないので、置いておくだけ
- 降車アラート：降りる駅に近づくと通知。寝過ごし防止に
- 目的地は全国の駅から検索OK。日本語／English対応

インストール不要、スマホのブラウザで開くだけ。無料です。
位置情報は端末内でのみ処理し、サーバーには保存しません。

👉 https://yamato015.github.io/test_fable/

まだβ版です。「次にこの機能が欲しい」の投票もフォームにあるので、
ぜひ触って教えてください。
```
