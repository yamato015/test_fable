# エキココ 公開ベータのローンチ

更新: 2026-10-26

## 公開先

- 紹介ページ: https://yamato015.github.io/test_fable/lp.html
- アプリ: https://yamato015.github.io/test_fable/
- 感想・不具合: ekikoko.app@gmail.com（アプリ内の「メールで感想を送る」からメールを作成）

鉄道会社との提携を待たず、現在のWeb/PWAを無料の公開ベータとして利用してもらう。ストア配信と実課金は今回開始しない。

## 機能の伝え方

- 端末の位置情報をもとに、近くの駅を大きく確認する。
- 車内モード、無料の乗り換えの目安、乗り方ガイドを使える。
- Plusの目的地設定・降車アラート・次駅予測などは、現在は料金請求のないデモ。
- GPSによる推定であり、地下等では更新できないことがある。画面ロック中やバックグラウンドの降車通知を保証しない。

## 確認したことと残ること

- 既存の18項目の動作テスト、固定座標での日英・縦横表示、10月23日の配信は確認済み。
- 10月26日のTally確認では、質問文とSubmitは表示されたが回答用の入力欄・選択肢がないことを確認。ローンチ時の感想導線を、既存の問い合わせ先へのメール作成リンクへ切り替える。
- メールリンクからメールを作成する動作までを案内する。受信箱の着信試験やテストメール送信はしていない。
- 実際の列車内・並走区間・地下から地上への復帰・電池消費の結果は引き続き収集する。
- 告知の投稿や鉄道会社への連絡はまだしていない。

混雑した電車で「今どの駅？」となったときに。

手元で近くの駅を大きく確認できるWebアプリ「エキココ」を無料ベータとして公開しています。
登録・インストール不要。車内モード、乗り換えの目安、乗り方ガイドを使えます。

https://yamato015.github.io/test_fable/lp.html

## 次の判断

- 同じ場所・路線での駅のずれや更新停止が繰り返されるなら、端末側の改善と公式データ・列車特定の連携を検討する。
- 出口やバリアフリーの要望が増えたら、公開データの範囲・鮮度・利用条件を確認する。
- 利用者数や満足度の目標値は、この文書では新たに決めていない。
