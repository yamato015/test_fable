- 既存のイラスト調SVGをヒーローの主役にしない

- 白基調の本文 + 実写利用シーン + アプリUIで構成する

- CTA:
  - 主: 「エキココを開く」
  - 副: 「できることを見る」
- 補助:
  - アカウント登録不要
  - ブラウザですぐ使える
  - PWA対応
- 写真:
  - 首都圏の通勤電車らしい実写/フォトリアル
  - ロングシート
  - 座席は進行方向を向かない
  - 扉上の案内表示
  - 立客などで表示が見えにくい状況
  - 手元のスマホで現在駅を確認できる文脈
