# Google Play ストア掲載情報 (下書き)

TWA(Trusted Web Activity)化の一環。Play Consoleへの入力用に、そのまま
コピペできる形でまとめてある。実際の登録・審査提出はオーナー自身の
Google Playデベロッパーアカウントで行う必要がある（$25の一回払い登録料込み）。

## アプリ名 (30文字以内)
```
エキココ - 今どの駅かすぐわかる
```

## 簡単な説明 (80文字以内)
```
混雑した車内でも、いまどの駅にいるかを特大表示。寝過ごし防止の降車アラート付き。
```

## 詳しい説明 (4000文字以内)
```
満員電車で座っていると、車内の電光掲示板が見えなくて「今どこ？」となった
経験はありませんか。エキココは、GPSで現在地を判定し、いま最も近い駅の名前を
画面いっぱいに表示するだけのシンプルなアプリです。

【できること】
・最寄り駅を特大表示 — 座った姿勢からのチラ見でも読める大きさ
・車内モード — 画面を点灯させたまま置いておける全画面表示
・降車アラート(プレミアム) — 降りる駅に近づくと通知。寝過ごし防止に
・次の駅予測(プレミアム) — 進行方向から次に停車する駅を予測表示
・目的地検索 — 全国の駅から目的地を検索可能
・駅の乗り方ガイド — QR/ICカード/紙のきっぷ/JR Passそれぞれの改札の通り方
・日本語・英語対応

【プライバシーについて】
位置情報は端末内でのみ処理し、外部のサーバーに送信・保存することは
ありません。詳しくはプライバシーポリシーをご覧ください。

【料金】
基本機能は無料。降車アラート・次の駅予測などは月額240円のプレミアム
プランでご利用いただけます（年額1,800円プランあり）。
```

## コンテンツのレーティング
Google Playの質問票に回答して自動判定（暴力・アダルト等の要素が無いため
「全年齢」相当になる見込み）

## データ セーフティ フォーム (重要・Google Playで必須)
「収集するデータ: 位置情報」を申告する必要があるが、**サーバー送信は
していない**ため「デバイス外に送信しない」を選択できる。この選択が
できるのは実装上の事実（位置情報はOverpass APIへの概算送信を除き
端末内処理）に基づいているため、実装を変更した場合はこの申告内容も
見直すこと。
