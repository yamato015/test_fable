# エキココ 中長期ロードマップ

北極星: 「電車内の"いまどこ？"という小さな不安を、日本で一番速く解消するアプリ」
原則: 一点突破 / privacyファースト(位置情報は端末内) / 機能はユーザーの声が決める

## フェーズ1: β検証 (〜1ヶ月)
- 目標: 毎日使われる証拠を取る
- 指標: テスター20〜50人 / 7日後再訪率20%+ / フィードバック10件+ / 致命バグ0
- タスク: 告知 / 独自ドメイン取得 / Tally確認
- ゲート: 再訪率20%未満 → 機能追加せずヒアリングに全振り

## フェーズ2: 収益化の初検証 (〜3ヶ月)
- 目標: 払う人の存在証明
- 指標: MAU 500〜1,000 / Stripe本番化 / 有料転換の最初の10人 / 投票1位機能の実装
- ゲート: 実課金3ヶ月で有料5人未満 → 価格・課金壁を再設計

## フェーズ3: 定着と拡大 (〜6ヶ月)
- 指標: MAU 3,000〜5,000 / MRR ¥10,000+ / AdSense審査申請 / 要望ベースのエリア拡大
- タスク: TWA(Android)ストア配信の判断 / レビュー導線
- ゲート: 伸びていればフェーズ4へ投資、横ばいなら低コスト運用で維持

## フェーズ4: 本格投資 (〜12ヶ月)
- 指標: MAU 10,000+ / MRR ¥50,000+
- タスク: iOSネイティブ化 + ライブアクティビティ(ロック画面に現在駅) / Apple Developer登録
- EN利用率10%超ならインバウンド強化

## フェーズ5: 選択肢 (12〜24ヶ月・データで選ぶ)
- インバウンド特化 / 降車駅連動のローカル収益(クーポン・提携) / B2B API提供

## やらないことリスト (全期間)
- 乗換案内の完コピ (Yahoo/Googleの土俵)
- データ無しの大型機能投資
- privacy原則を崩す機能

## 運用リズム
- 週次: Cloudflareの数字を共有 → 分析
- 月次: フェーズ指標と照合 → 次の一手を決定 (判断はオーナー、実装はClaude)
