# 外国人向け改札案内機能 実装計画

状態: 計画のみ (実装はトリガー条件を満たしてから / docs/roadmap.md の規律に従う)

## 解決する痛み (優先度順)
1. ICカード (Suica/PASMO) の買い方・チャージ・タッチの仕方 / Welcome Suica / モバイルSuica
2. 改札の通り方 (IC=タッチ、紙きっぷ=挿入して取る、広いゲート=スーツケース)
3. 残高不足時の精算機 (Fare Adjustment) の存在
4. 会社をまたぐ乗換 (JR⇔メトロは別料金・乗換改札の説明)
5. JR Passは自動改札不可 → 有人改札へ

差別化: Google Mapsが教えない領域 × エキココの「いまこの駅にいる」文脈。

## 実装トリガー (どちらかで着手)
- Tally機能投票で「外国人向け乗り方ガイド」が1位
- 英語モード利用率10%超 or 海外からの訪問が明確

## Phase A: 静的ガイド (MVP・実装1日)
- ENモード時にメイン画面へ「🎫 Station Guide」→ モーダルで上記5トピック
- 既存i18n基盤 (data-i18n) に乗せる。完全オフライン・追加容量ほぼゼロ・外部依存ゼロ
- 図解は絵文字+自作SVG (著作権リスクなし)

## Phase B: 文脈連動 (1〜2日)
- 路線名プレフィックスから事業者判定 (JR/東京メトロ/都営/私鉄)
- 現在駅連動の注意表示 (例:「ここはJRの駅。メトロのパスは使えません」)
- 乗車路線の推定が事業者をまたいだら「別会社=運賃が別」警告

## Phase C: 本格インバウンド (投資判断後)
- 中国語(簡体)・韓国語 (STRINGSに追加するだけの構造は済み)
- 出口案内 (OSM出口データの品質検証が前提)
- 料金: 訪日客にサブスクは不適合 → 「7日間パス」買い切り (例: ¥500) をStripeに追加
- 配布: Reddit r/JapanTravel 等の英語圏チャネル

## 成功指標
- ENユーザーのガイド開封率 30%+
- 「役に立った」フィードバック
- Phase C: 7日パス購入数

## リスク
- 内容の陳腐化 → 金額・固有名詞は最小限にし「仕組みの説明」中心
- 日本語圏SNSでは訪日客に届かない → チャネルを分ける
